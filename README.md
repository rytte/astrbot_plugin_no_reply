# 自主沉默

一个简简单单的沉默插件，提供一个沉默工具，和一段可选的引导提示词。

## 模型工具

**工具定义**

```python
async def no_reply(self, event: AstrMessageEvent) -> None:
    event.clear_result()
```

* `self` 是插件实例，`event` 由 AstrBot 传入，不是模型需要填写的参数。
* `no_reply` 不需要任何参数，调用时传入空对象 `{}`。

**工具描述**

```text
选择本轮不回复，结束当前模型回复流程，不发送任何消息。

决定保持沉默时仅调用本工具，不要先输出文字、解释原因或输出占位内容，
也不要同时调用其他工具。需要正常回复时不要调用本工具。
本工具无需参数，不会永久静音，也不会影响后续消息。
```

## 可选提示词注入

通过提示词注入告诉模型何时需要沉默，默认关闭。

提示词会追加到原系统提示词后，不会替换人格。

默认提示词：

> 你可以根据当前对话和已有指令，自主选择回复或保持沉默。决定不回复时，仅调用 no_reply 工具，不要先输出文字、解释沉默理由、发送占位内容或同时调用其他工具。需要回复时正常回复，不要调用 no_reply。
